00Before the first commit

Why a fork

Stremio Web is a very good player with a huge addon ecosystem. But it is built for one person with one cloud account. A household that shares one home server needs different things:

  • Everyone with their own watch history and Continue watching, without sharing a login.
  • A library of the files that are already on the server's disk.
  • New episodes that turn up on their own, without anyone hunting for them.
  • Nobody's viewing habits leaving the house.

So the plan was simple: keep Stremio's player and its stremio-core engine, and build a household around them. A Node and Express backend next to the React UI, one SQLite file for everything, and Cloudflare Access in front so only invited people can sign in.

01November 13

Day one: a household around a player

The first public release landed with fresh history; earlier private work was left out on purpose. It already had the bones of everything that followed:

  • Profiles with an optional PIN and a kids mode, each with its own library, history and settings.
  • Downloads to the server's own disk through Transmission, with quality profiles and a swarm check that says whether a release is alive.
  • Sentinel, which follows a show and fetches new episodes, a few seasons, or all of it.
  • Smart filters from TMDB, a Home hero banner, the server library, signed stream links and an admin panel.
  • An AI copilot with one hard rule: it can only stage a download. A person presses Confirm.

The stream source is an operator setting. Nothing is built in, and the repository ships no sources at all.

That decision shaped the project from the start: HomeBot Cinema is a manager for your own server, not a source of content. The same evening the README got real screenshots and the first demo video.

02November 15–16

Keep the core small

With features piling up, the risk was a fork nobody could keep in sync. The answer was a plugin architecture. Each optional feature now lives in plugins/<id>/ with a manifest, its own guide for contributors, server code, UI and tests. The loader isolates failures, and the UI offers named slots where plugins plug in.

The copilot, Smart filters, themes, Telegram alerts and Google Drive moved out of the core into plugins. The rules became tests rather than good intentions:

  • A boundary test: the core never imports a plugin, and plugins never import each other.
  • A content guard: no sources, scraper URLs or release names anywhere in the repository.
  • A fetch guard: the app never calls Stremio's own account API.
  • A list of every upstream file we touch, checked by pnpm check:upstream, so merging new Stremio Web releases stays possible.

Streaming-server settings became admin-only, and the project got its first website.

03November 16–17

A real Mac app

Browsers can't play everything. HEVC, Dolby audio and embedded subtitles meant the server had to transcode, which is slow and wasteful. The macOS app solves that with Tauri 2 and libmpv: the same web interface in a native window, with mpv drawing the video underneath and playing the file exactly as it is stored.

A first-run screen asks for the server's address, so one download fits every install. Home mode uses the local network address when you are at home. CI builds a versioned DMG and attaches it to a GitHub Release on every tag.

04November 17

Watching like a streaming service

The busiest day. The goal: make watching at home feel as smooth as the big streaming apps.

  • Skip intro, recap and credits, using chapter markers in your files first and the community IntroDB second, with marks on the seek bar and Up next as soon as the credits roll.
  • Continue watching that knows what's next: it reads the furthest episode you watched and offers the one after it. An Upcoming row lists episodes airing in the next two weeks.
  • Now playing and watch stats: who is watching what, and a Tautulli-style history kept on your own server.
  • Movie collections, More like this, a Direct filter for links that start at once, and acoustic subtitle auto-sync that lines subtitles up with the voices.
  • 4K AI upscaling in the Mac app with Apple's MetalFX spatial scaler, with live GPU stats.

It was also the day the project got its own look. Stremio's default artwork was replaced with original images, including a captain mascot made through a small art pipeline, and each install can swap in its own avatars and art privately.

05November 17–19

The UI review

Features are only half of it. A structured review went through the whole interface in seven phases:

  • Fixes for the profile picker in WebKit, Escape that closes menus before it leaves the player, and clear loading and empty states.
  • One accent colour system, with text contrast checked by tests against the 4.5:1 guideline.
  • Native macOS menus with keyboard shortcuts and an overlay title bar.
  • Play-first title pages and one-click playback: Play resumes, picks the next episode, or finds the best release for you.
  • A right-click menu, a player overhaul with one Audio and subtitles panel, Search with top results, Home rows you can hide and reorder, and a Calendar with month and agenda views.

06November 19–20

Couch mode

A media app on a Mac mini under the TV should work from the sofa. The Mac app now reads Xbox, PlayStation and other game controllers natively through Apple's GameController framework, sixty times a second.

The D-pad moves from poster to poster and row to row like a console, the mouse cursor hides while you use the pad, and the triggers scrub through a film. A controller HUD, a quick menu and an on-screen keyboard for search finished the job. Settings › Controllers lets you remap every button.

07November 20–21

Every screen in the house

  • Ratings everywhere: Rotten Tomatoes, Metacritic, IMDb and Letterboxd on posters and title pages, through MDBList.
  • An Android app built with Kotlin, Jetpack Compose and Media3, for phones, tablets and Android TV.
  • Remote and cast: pick something on your phone, send it to the Mac in the living room, and control it from the couch. It runs through your own server, with no Chromecast needed.
  • A mobile layout for small screens, and macOS Now Playing: media keys, AirPods and Control Center drive the player.

The website got fresh screenshots, and then the redesign you are reading now.

08Throughout

What stayed true

Moving this fast only works with a few rules that never bend. These held from the first commit to the last:

  • The AI suggests; people decide. The copilot stages, a person confirms, and kids profiles can't stage at all.
  • No sources in the repository. A test fails the build if one sneaks in.
  • Fail closed. No valid sign-in, no access. The developer login only works in development mode.
  • Small core, optional plugins. If it isn't needed by every household, it's a plugin.
  • Every backend change ships with a test. There are 69 test files today.

Much of the work ran in parallel branches with AI coding agents as pair programmers. AGENTS.md, at the root and in every plugin, is the map they read first, and the guardrail tests keep everyone, human or not, inside the lines.

09Next

What's next

  • Signing and notarizing the Mac app, and bundling libmpv so Homebrew isn't needed.
  • Windows and Linux desktop apps on the same design.
  • A real merge with upstream Stremio Web, now that the tooling to track our changes is in place.
  • Skip times for anime, and fewer outside services over time.

Want to follow along or help? The code, the issues and the guides are all on GitHub.
