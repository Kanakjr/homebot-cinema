Why we built it

Stremio Web is a great player with a great addon ecosystem, but it is made for one person with one account in the cloud. A household needs something else: everyone on the same box, each with their own watch history, a library of the files you already have, new episodes that arrive by themselves, and no account with anyone but you.

So we forked it and grew a small server around it. Everything (profiles, history, library, settings) lives in one SQLite file and one folder you can back up. Only the people you invite can sign in.

Principles

  • Yours. Runs on a Mac mini, NAS or mini PC. Your data never leaves it.
  • Small core, opt-in extras. Anything not everyone wants is a plugin.
  • Suggest, never act. The AI copilot stages things; a person presses Confirm.
  • Close to upstream. We keep merging Stremio Web instead of drifting away.
  • Sources are yours to choose. The repo ships no stream sources.

What it adds on top of Stremio Web

The Stremio player and addon catalogs are still there. Around them:

Profiles for everyone

Up to 8, with avatars, optional PIN and kids mode. Each has its own library, Continue watching and settings.

Server library

Scans your movie and TV folders, matches titles, plays straight from the server and badges what is new.

Downloads to your disk

Through Transmission, with quality profiles (4K, HD, direct play, space saver, your own) and a live swarm check.

Sentinel

Keeps shows up to date: new episodes only, chosen seasons, or everything. Never re-fetches what you deleted.

A better player path

Deep HLS buffer, smooth HEVC handling, signed expiring links for VLC and friends. Native apps play files as they are.

Universal ratings & details

Rotten Tomatoes, Metacritic, IMDb and Letterboxd scores on poster cards across Home and Discover, with widened details.

Admin and live updates

Overview, people, activity log; pages refresh by themselves; a daily database snapshot.

Watch stats & history

Tautulli-style play logs kept on your server: hours per day, streaks, top devices, and CSV export.

Casting & remote control

Push-to-play casting from your phone to your living room Mac Mini, with a real-time virtual remote control.

yours

Your own plugins, hooks and slots. pnpm plugin:new my-plugin

Switch them on

# .env
CINEMA_PLUGINS=find,themes,ai,telegram

# or data/plugins.json (gitignored, survives rebuilds)
{ "enabled": ["find", "themes", "ai"] }

Admins see every plugin, and why one is not active, at /api/plugins.

Write one

// plugins/hello/server/index.js
module.exports = {
  register(ctx) {
    if (!ctx.config.get('HELLO_KEY')) return ctx.disable('HELLO_KEY not set');
    ctx.hooks.on('notify', (n) => ctx.log.info(n.text));
    ctx.app.get('/api/hello', (req, res) => res.json({ hi: req.login.email }));
  },
};

UI plugins add to named slots: routes, top-bar buttons, settings sections, accent colours. Plugin guide.

Get started

  1. Clone and configure

    git clone https://github.com/Kanakjr/homebot-cinema
cd homebot-cinema
cp .env.example .env
cp data/addons.example.json data/addons.json
cp docker-compose.example.yml docker-compose.yml

    Point the media folders in docker-compose.yml at your disk, and set your login (Cloudflare Access) in .env.

  2. Start it

    docker compose up -d --build   # http://localhost:3002

    Create a profile for everyone on the "Who's watching?" screen.

  3. Add what you want

    A free TMDB key turns on Smart filters; a Gemini key and CINEMA_PLUGINS=…,ai turn on the copilot. Add the addons you have the right to use to data/addons.json.

Where it is going

  • Our own metadata: a TMDB-backed catalog served directly from your server, so browsing does not depend on outside catalogs.
  • Native desktop ports: signed Windows installer and Linux AppImage/Flatpak ports.
  • Automatic desktop updates: seamless in-app updater for macOS and future desktop platforms.
  • Advanced subtitles: sidecar subtitle auto-matching and local library search.

Responsible use. HomeBot Cinema does not host, index, provide or recommend any media. It is a client for the sources you configure and a manager for your own server. Use it for media you have the right to access.
