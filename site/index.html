Design Philosophy

Why we built HomeBot Cinema

Stremio Web is an exceptional player with an expansive addon catalog, but it was designed for a single individual with one account hosted in the cloud. A real household needs something else: everyone streaming from the same local box, each person with their own separate watch history and Continue Watching queue, a library of the media files already sitting on your NAS, and new episodes that arrive automatically without manual torrent hunting.

We forked Stremio Web and engineered a robust Node/Express backend around it. Everything—profiles, watch progress, downloads, and plugins—resides in a single SQLite database and a clean data/ folder. Protected by Cloudflare Access zero-trust authentication, only the people you invite can ever sign in.

Core Commitments

  • Data Sovereignty: Runs locally on your Mac mini, NAS, or PC. Your watch history, library, and settings never leave your server.
  • Small Core, Modular Plugins: Core handles playback and household synchronization. Everything else is an isolated plugin.
  • Suggest, Never Force: The AI copilot stages downloads and monitors into interactive cards; a human must always click Confirm.
  • Zero Tracked Piracy Sources: The repository ships no indexer URLs or scraper endpoints. Operator sources are strictly external.
  • Active Upstream Sync: We continuously rebase and merge changes from official Stremio Web releases to maintain compatibility.

Extensibility

Plugins: Run only what your household needs

Each plugin is an isolated bundle with server code, UI slots, and automated tests. Enable or disable any feature with a single environment flag or through the Admin UI.

find
Smart Filters & Quick Picks
Enabled by default
Slot: Discover Tab Requires: Free TMDB Key

Advanced catalog filtering powered by TMDB Discover. Find movies and shows matching precise household criteria.

  • Streaming provider filtering: See what is available on Netflix, Apple TV+, Prime, or Disney+ in your country.
  • Precision sliders: Filter by IMDb/TMDB rating, vote count, release year, runtime, and primary language.
  • 40 Ready Quick Picks: Curated shortcuts for Top 250, Hidden Gems, Short on Time (<90 min), and award winners.
Config: TMDB_API_KEY, WATCH_REGION
metalfx
MetalFX 4K AI Upscaler
Enabled by default
Slot: Player HUD Platform: macOS Desktop

Real-time Apple MetalFX AI Spatial Super-Resolution built exclusively for the macOS native desktop player.

  • Local GPU Acceleration: Upscales 1080p and 720p streams to razor-sharp 4K Ultra HD on Apple Silicon.
  • Zero Transcode Load: The server streams the raw lightweight file; the client Mac performs the AI super-resolution.
  • Live Telemetry HUD: Real-time overlay reporting frame rate (up to 120 FPS), input/output resolution, and sub-0.5ms GPU times.
Zero server config (Apple Silicon Mac)
skip
Skip Intro, Recap & Credits
Enabled by default
Slot: Video Player Source: Chapter Markers + IntroDB

Smart detection of television intros, recaps, and closing credits with seekbar markers and auto-skip.

  • Seekbar Chapter Marks: Visual chapter indicator bars highlighting exact intro and credit boundaries.
  • Auto-Skip Option: Configurable per profile to automatically jump over intros without lifting a finger.
  • Instant Up Next: Automatically presents the next episode countdown the moment closing credits begin.
Config: SKIP_INTRODB_URL (or off for local only)
mdblist
Universal Card Ratings
Enabled by default
Slot: Poster Cards & Details Requires: MDBList Key

Critic and audience score overlays rendered directly onto poster cards across Home, Discover, and Search.

  • Rotten Tomatoes: Displays both the Tomatometer critic score and Audience Popcornmeter rating.
  • Metacritic & IMDb: Metascore badges alongside IMDb ratings and Letterboxd community scores.
  • Cinematic Details: Widens the title details pane to showcase high-resolution backdrops and audio badges.
Config: MDBLIST_API_KEY
nowplaying
Now Playing & Watch Stats
Enabled by default
Slot: Admin + Route #/stats Storage: Local SQLite

Real-time playback telemetry for administrators and comprehensive Tautulli-grade watch analytics.

  • Live Activity Monitor: See who is streaming, on what device, bitrate, and direct-play vs transcode status.
  • Personal Watch Stats: Track daily hours watched, viewing streaks, hourly habit heatmaps, and top titles.
  • Privacy-First: Non-admins only see their own history; admins can view aggregate household metrics or export CSV.
Config: NOWPLAYING_KEEP_DAYS (default 730)

Enabled by default

Complete visual customization saved independently per household profile.

  • 10 Accent Palettes: Cinema Orange, Electric Purple, Cyber Blue, Emerald, Sunset, Rose, and more.

  • Adjustable Radius: Slider control from sharp modern corners (4px) to soft rounded cards (18px).
Zero server configuration required

ai
AI Copilot (Gemini)
Opt-in
Slot: Topbar Sparkle Drawer Model: Gemini 2.5 Flash

An intelligent media copilot that recommends titles, checks server availability, and stages downloads.

  • Natural Language Queries: Ask complex queries like "find a 90-minute thriller with no gore" or "what did I start last week?"
  • Staged Action Safety: It can only stage a download or monitor card; nothing begins downloading until you press Confirm.
  • Zero Personal Leakage: Prompt context includes titles only—never personal names, emails, PINs, or raw file paths.
Config: GEMINI_API_KEY, GEMINI_MODEL
telegram
Telegram Household Alerts
Opt-in
Slot: Server Hook Dispatch Integration: Telegram Bot API

Automated notifications broadcast to your family Telegram group or administrator chat.

  • Sentinel Notifications: Receive instant alerts when a newly aired episode is detected and queued.
  • Completion Alerts: Broadcasts a message when a large 4K movie download finishes and is ready for playback.
  • Storage Warnings: Notifies administrators when disk storage exceeds 90% capacity.
Config: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
gdrive
Cloud Roots & Smart Tiering
Opt-in
Slot: Library Scanner Integration: rclone / Network Mounts

Mount remote cloud storage (Google Drive, Dropbox, OneDrive) as secondary offline-safe library roots.

  • Offline Safety: Roots marked with .cinema-root are protected from accidental pruning if the cloud mount unlinks.
  • Automated Tiering: Move watched movies and completed show seasons from local NVMe/SSD to cold cloud storage.
  • Seamless Playback: Cloud-hosted titles appear seamlessly in your unified library alongside local files.
Config: LIBRARY_EXTRA_MOVIES_DIRS, MEDIA_ROOTS

Enabling & Configuring Plugins

Plugins can be toggled using the CINEMA_PLUGINS environment variable or managed live through the Admin UI at #/admin/plugins.

# .env file configuration
CINEMA_PLUGINS=find,themes,skip,nowplaying,mdblist,remote,controllers,similar,collections,metalfx,ai,telegram

# Or survive container rebuilds with data/plugins.json:
{
  "enabled": ["find", "themes", "skip", "nowplaying", "mdblist", "metalfx", "ai"]
}

Admins can audit plugin status, startup logs, and missing configuration keys anytime via the /api/plugins REST endpoint.

Quick Setup

Get started in three steps

Deploy on any Mac mini, NAS, or Linux server using Docker Compose.

1

Clone & Configure

Clone the repository and prepare your environment files.

git clone https://github.com/Kanakjr/homebot-cinema.git
cd homebot-cinema
cp .env.example .env
cp data/addons.example.json data/addons.json
cp docker-compose.example.yml docker-compose.yml

Mount your existing Movies and TV folders in docker-compose.yml.

2

Launch Server

Start the container suite with Docker Compose.

docker compose up -d --build

Open http://localhost:3002 in your browser to begin first-time household setup.

3

Profiles & Addons

Create household profiles on the "Who's watching?" screen and add your favorite metadata and subtitle addons to data/addons.json.

Add a free TMDB key in .env for Smart Filters, and an optional Gemini key for AI Copilot.
