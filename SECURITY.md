# Security policy

HomeBot Cinema is meant to run on your own machine behind an authenticating proxy (Cloudflare Access). If you find a way
around the sign-in, to read another household member's data, to make the copilot act without a confirmation, or to reach
files outside the configured library folders, please report it **privately**: use GitHub's *Report a vulnerability*
button on the repository's Security tab instead of a public issue.

Please leave real tokens, addon URLs and personal data out of reports.
